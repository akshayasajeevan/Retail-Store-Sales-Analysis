# Retail Store Sales Analytics

## AI-Driven Data Analytics Project

This project analyzes retail sales data using **Microsoft Excel** and **Power BI**.

### Tools Used
- Microsoft Excel – Data cleaning and preparation
- Power BI – Data analysis and dashboard creation

### Project Work
- Cleaned and prepared the raw sales data in Excel
- Created Pivot Tables for basic analysis
- Built a data model in Power BI
- Created DAX measures and interactive dashboards
- Analyzed sales, customers, products, and payment methods
- Created a Business Insights dashboard with key findings and recommendations

### Dashboards
1. Home
2. Executive Dashboard
3. Customer Analysis
4. Product Analysis
5. Business Insights

### Key Insights
- Total sales: approximately **₹1.62M**
- Total transactions: approximately **13K**
- Medium Purchase Category generated the highest revenue
- Low Purchase Category represents the largest customer segment
- Online sales slightly exceeded in-store sales
